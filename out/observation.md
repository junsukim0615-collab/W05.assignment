# Week 5 관찰 기록

## Task 1
- `/31`, `/32`는 전통적인 서브넷 계산 기준으로 사용 가능한 호스트 범위가 없다고 정하여 `(None, None, 마지막 주소)`를 반환한다. 마지막 값은 API의 broadcast 칸을 유지한 계산상 주소이며, 특히 `/32`의 실제 브로드캐스트 전송을 뜻하지 않는다. RFC 3021의 점대점 `/31` 해석은 이 구현에 적용하지 않았다.
- `10.20.30.70`은 `10.0.0.0/8`, `10.20.0.0/16`, `10.20.30.0/24`, `10.20.30.64/26`에 모두 일치하며, 가장 긴 `/26`의 `lab-rack-2`를 선택한다. 기본 경로 `0.0.0.0/0`까지 포함하면 일치 경로는 총 5개다.
- 동일한 네트워크와 prefix 길이를 다시 추가하면 마지막 next hop으로 갱신한다. 길이만 같고 서로 다른 정상 네트워크는 한 목적지에 동시에 일치하지 않는다. 조회는 저장된 모든 경로를 비교하므로 경로 수 N에 비례하는 O(N)이다.
